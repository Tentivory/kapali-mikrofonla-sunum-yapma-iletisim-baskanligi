# Kapalı Mikrofonla Sunum Yapma İletişim Başkanlığı

> **Resmi duyuru:** Bu yazılım bir şaka değildir. Şaka gibi duruyorsa bu, protokolün başarısıdır.

## 1. Kurumsal kimlik

T.C. İletişim Başkanlığı — *Kapalı Mikrofon Kriz Masası* (KM-KM), çevrimiçi toplantılarda vatandaşın on dakika boyunca coşkuyla konuşup kimsenin duymamasını **milli ses egemenliği ihlali** sayar.

Bu ihlal:

- bilimsel olarak kanıtlanmamıştır,
- diplomatik olarak tanınmamıştır,
- buna rağmen **tutanaklıdır**.

Mikrofon kapalıyken söylenen her cümle, evrenin en kalabalık arşivine gider: **kimsenin açmadığı iç ses.**

## 2. Bu yazılım ne yapar?

`baskanlik.py` gerçekten çalışır.

1. Size bir konu sorar.
2. Dört slayt boyunca konuşturur.
3. Mikrofonun kapalı olduğunu yasal ciddiyetle kaydeder.
4. Sonunda mute'u açar; işiş bitmiştir.
5. Resmi tutanak basar.

Kurulum yoktur. Bağımlılık yoktur. Pismanlık vardır.

```bash
python3 baskanlik.py
```

## 3. Yasal dayanak (çok ciddi)

- **Madde 1:** Mute tuşu anayasal haktır.
- **Madde 2:** Farkındalık vatandaşlık ödevidir.
- **Madde 3:** "Ben konuşuyordum ya" cümlesi basın bildirisidir.
- **Madde 4:** Chat'e geç yazılan "mikrofonum açık mı?" gecikmiş başvurudur, reddedilir.
- **Madde 5:** Ekran paylaşımı açık mikrofon kapalı ise bu **görsel demokrasi / işitsel sessizlik** rejimidir.

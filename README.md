# kapali-mikrofonla-sunum-yapma-iletisim-baskanligi
Kapalı mikrofonla on dakika konuşmayı resmi iletişim felaketi, milli ses egemenliği ihlali ve toplantı protokolü sapması sayan; sessizliği yayın, 'ben konuşuyordum ya' cümlesini basın bildirisi ilan eden İletişim Başkanlığı. Gerçekten çalışır. Mikrofonlar artık vatandaştır.
